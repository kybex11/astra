★ ASTRA CLIENT 1.16.5

v1.1.0 PRO

Клиент нового поколения на Fabric 1.16.5. Оснащен воксельным 3D движком косметики, современным Web ClickGUI на базе Ultralight, локальной базой SQLite3 и передовыми PvP алгоритмами.

🧊 3D Voxel Dragon Wings & Halo 🌐 Web GUI (Ultralight CEF) 🗄️ SQLite3 База данных 🎯 Bow Prediction & Fast Snap 🗺️ Топографическая Миникарта ⚡ Instant Sneak (Резкий шифт)
🎮 Горячие клавиши в игре Управление
Главное Web GUI меню: RIGHT SHIFT
Редактор HUD & интерфейса: RIGHT ALT
Поставить Waypoint на миникарте: B
Большая топографическая карта: M
✨ Особенности релиза НОВОЕ
• Пометка "Astra Client" в Tab-листе игроков как в Lunar
• Объемная 3D косметика: настоящие Minecraft-воксели с тенями
• Резкий / Плавный Sneak: настройка анимации приседаний
• Интеллектуальный AimAssist: мгновенная наводка и баллистика лука
• JumpCircles & TargetESP: 3D кольца прыжка и аура таргета

Окружение Java & Среда Java 17

Для запуска Minecraft 1.16.5 с Fabric и миксинами используется Eclipse Temurin / Adoptium JDK 17 с оптимизацией G1GC.

Локальная база данных SQLite3 ВКЛЮЧЕНО

Все метки Waypoints, пресеты HUD, конфиги модулей и профили сохраняются в сверхбыструю локальную реляционную БД astra_storage.db.

Web UI Движок (Ultralight) CEF / Ultralight

Рендеринг интерфейса ClickGUI с аппаратным ускорением HTML5/CSS3. Клавиша вызова в игре: Правый Shift.
